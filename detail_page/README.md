# 상세페이지 제작 폴더 (Product Detail Page)

## 사용 방법

1. **이미지 넣기**:
   * 이 폴더 안의 `images/` 폴더에 상세페이지에 들어갈 이미지 파일들(예: `1.jpg`, `2.jpg`, `main.png` 등)을 모아두세요.

2. **이미지 설명 작성하기**:
   * `description.txt` 파일에 각 이미지별로 넣고 싶은 문구, 핵심 포인트, 제품 설명, 강조하고 싶은 타이틀을 적어두세요.

3. **요청하기**:
   * "상세페이지 만들어줘" 라고 말씀해 주시면, 제가 감각적이고 고급스러운 디자인의 HTML 상세페이지를 제작해 드립니다!
